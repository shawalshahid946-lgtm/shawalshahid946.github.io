FREE HOSTING (GitHub Pages):
1. Sign in or create a GitHub account at https://github.com
2. Create a new PUBLIC repository named shawalshahid946.github.io (if that username is available; if not, use any repository name).
3. Open the repository and choose Add file > Upload files. Extract this ZIP first and upload index.html from the website folder (README is optional).
4. Click Commit changes.
5. Open repository Settings > Pages. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. GitHub will show the website URL in Settings > Pages once published. It can take a few minutes.

Important: The site files are prepared, but the website is NOT live until they are uploaded to a hosting account. I cannot sign in to or publish to your personal GitHub account on your behalf.
